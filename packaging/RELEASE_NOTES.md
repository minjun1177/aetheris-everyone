## What's new in 1.2.0

**A window like a desktop chat app**
- **Settings open as a page** in the window instead of a pop-up, with a section list on the left.
- **Switch the AI model** from the chip under the message box.
- **Token usage** is shown per reply, per chat and per month (Settings → Usage).
- **Select part of a reply** to quote it and ask about it.
- **Edit or retry your last request**, and try again from an error card.
- **Search chats** from the sidebar; new chats are named by the AI.
- **Save a chat as a Markdown file.**
- A notification when the AI finishes or needs your permission while the window is in the background.

**New**
- **Memory**: the AI can remember standing facts about you between chats — only after you allow each one. See and delete them in Settings.
- **Folder rules**: standing instructions for each work folder (folder menu → Folder rules).
- **Saved requests**: keep requests you use often and run them with one click.
- **Schedules**: run a request once, every day or every week while the app is open.
- **PowerPoint**: the AI can create .pptx decks.
- **Pictures in the folder**: the AI can look at images to sort or describe them (models that see images).
- **PDFs on the web** can be read.
- **Long chats** keep going: the start is summarised instead of dropped.
- A busy AI service is asked again before giving up.
- **Undo copies** are kept for a chosen time (90 days by default) and their size is shown.

**Safer**
- Every program run is asked, even after "allow for this chat".
- Allowing a read outside the work folder no longer allows changes there.
- Deleting or moving a folder that holds the work folder, the app's data or your home folder is refused.
- The Undo card of a reply cut short by closing the app comes back at the next start.
- "Open" never starts a program disguised as a shortcut file (.url, .scf and similar); it shows the file in its folder instead.

**Fixed**
- Large photos are shrunk for the AI instead of being dropped.
- edit_file keeps Windows line endings.
- Renaming a chat while the AI works on it is no longer lost.
- An upload cut off on the way is rejected instead of saved half-written.
- A damaged PDF is reported instead of ending the reply.
- Making the desktop shortcut works when your Windows user folder has an apostrophe (e.g. O'Neil).

## 1.2.0 새 기능과 수정

**데스크톱 채팅 앱 같은 화면**
- **설정이 팝업이 아니라 창 안의 페이지**로 열립니다. 왼쪽에 항목 목록이 있어요.
- 입력창 아래 칩에서 **AI 모델을 바로 바꿀** 수 있어요.
- **사용량(토큰)**을 답변별, 대화별, 월별로 보여 줍니다 (설정 → 사용량).
- 답변의 **일부를 드래그해서** 그 부분에 대해 바로 물어볼 수 있어요.
- **마지막 요청을 고치거나 다시 시도**할 수 있고, 오류 카드에서 [다시 시도]를 누를 수 있어요.
- 사이드바에서 **대화를 검색**하고, 새 대화는 AI가 제목을 붙여 줍니다.
- **대화를 Markdown 파일로 저장**할 수 있어요.
- 창을 내려 둔 사이 AI가 일을 끝내거나 허락을 기다리면 알림을 보냅니다.

**새 기능**
- **기억**: 대화가 바뀌어도 AI가 나에 대한 사실을 기억합니다. 하나하나 허락한 것만 저장하고, 설정에서 보고 지울 수 있어요.
- **폴더 규칙**: 작업 폴더마다 늘 지킬 규칙을 적어 둘 수 있어요 (폴더 메뉴 → 폴더 규칙).
- **저장한 요청**: 자주 쓰는 요청을 저장해 두고 한 번에 실행해요.
- **예약**: 요청을 한 번, 매일, 매주 정해진 시간에 실행합니다 (앱이 켜져 있을 때).
- **PowerPoint**: AI가 .pptx 발표 자료를 만들 수 있어요.
- **폴더 속 사진**: AI가 사진을 보고 분류하거나 설명합니다 (이미지를 보는 모델).
- **웹의 PDF**도 읽습니다.
- **긴 대화**는 앞부분을 버리지 않고 요약해서 이어 갑니다.
- AI 서비스가 바쁘면 포기하기 전에 다시 요청합니다.
- **되돌리기용 사본**을 정한 기간(기본 90일) 동안 보관하고 크기를 보여 줍니다.

**더 안전하게**
- "이 대화에서 허용"을 눌러도 프로그램 실행은 매번 물어봅니다.
- 작업 폴더 밖 읽기를 허락해도 그곳의 파일을 바꾸는 것까지 허락되지는 않습니다.
- 작업 폴더, 앱 데이터, 홈 폴더를 담은 폴더를 지우거나 옮기는 것은 거절합니다.
- 앱을 닫아 중간에 끊긴 답변의 되돌리기 카드가 다음 실행 때 다시 나타납니다.
- [열기]는 바로가기 파일(.url, .scf 등)로 위장한 프로그램을 실행하지 않고, 파일이 있는 폴더를 보여 줍니다.

**고친 점**
- 큰 사진은 버리지 않고 줄여서 AI에게 보여 줍니다.
- 파일 고치기가 Windows 줄바꿈을 유지합니다.
- AI가 일하는 동안 바꾼 대화 이름이 사라지지 않습니다.
- 중간에 끊긴 업로드는 반쪽짜리로 저장하지 않고 거절합니다.
- 손상된 PDF는 답변을 끝내지 않고 알려 줍니다.
- Windows 사용자 폴더 이름에 작은따옴표(')가 있어도 바탕화면 바로가기를 만들 수 있어요.

## 다운로드 / Download

| 내 컴퓨터 | 받을 파일 |
| :--- | :--- |
| **Windows 10 / 11** | `AetherisEveryone-Windows.exe` |
| **Mac (M1 / M2 / M3 / M4)** | `AetherisEveryone-macOS-AppleSilicon.dmg` |
| **Mac (Intel)** | `AetherisEveryone-macOS-Intel.dmg` |
| **Linux** | `AetherisEveryone-Linux-x86_64.tar.gz` |

받은 파일을 **더블클릭**하면 끝입니다. 처음 실행하면 설정 도우미가 AI 준비를 화면에서 안내해 줍니다. 터미널은 필요 없습니다.

- **Windows**: "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명 인증서가 없는 무료 앱이라 뜨는 안내입니다.)
- **Mac**: dmg를 열고 앱을 **응용 프로그램** 폴더로 끌어다 놓으세요. 처음 열 때 "확인되지 않은 개발자" 창이 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 누르세요.
- **Linux**: 압축을 풀고 `AetherisEveryone`을 더블클릭하세요. 설정 → 정보에서 바로가기를 만들 수 있어요.

Double-click the downloaded file; the first-run guide sets up the AI on screen. No terminal needed.
